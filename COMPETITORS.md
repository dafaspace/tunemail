# Tunemail: кто уже делает похожее (сверка 23 окт - 3 ноя 2026)

Зачем этот файл: чтобы через месяц не проверять заново. Девять агентов в три
прохода, каждый признак засчитан только с двумя независимыми источниками (один
из них - живая страница или официальная документация). Метки: **V** - проверено
по первоисточнику, **C** - заявлено вендором или прессой, **?** - не проверено.

## 2. Отправить песню так, чтобы она играла прямо в мессенджере

- Внутри чата играют только "свои" домены: YouTube почти везде, Apple Music в
  iMessage, Spotify в Discord. Стороннему сайту в WhatsApp и Instagram достаются
  только картинка, заголовок и описание.
- iMessage проигрывает прямой MP4 из og:video, но не HTML-плеер
  (V: Apple TN3156). Discord проигрывает прямой MP4 (C).
- Отрывки iTunes: только поток с сервера Apple, без кеша и перехоста (V:
  performance-partners.apple.com/search-api). Deezer API: только некоммерческое
  использование (V: developers.deezer.com/termsofuse). Значит, звук в карточке
  мессенджера для вышедших треков нам недоступен.
- Сохранить трек к себе одним нажатием: Apple Music (MusicKit JS) и TIDAL
  (OpenAPI, PKCE) можно с нашей страницы; Spotify нельзя (лимит 5 пользователей),
  Deezer нельзя (условия).
- Реалистичный путь в Telegram: бот, где клип с YouTube играет плеером самого
  Telegram, а под ним кнопки сервисов.

## 3. Страница работ автора: есть ли у кого-то (6 проверяющих, 24 окт)

Проверено около 35 продуктов. **Вердикт всех шести: частично верно.**

**Ни у кого нет** страницы самого участника записи (продюсер, композитор,
звукорежиссёр), где каждая строка - конкретная запись с его ролью, включая
релизы, где он не основной артист, и у каждой строки: отрывок, встроенный клип,
ссылки на тот же трек минимум в трёх сервисах, виджет для своего сайта,
статистика для владельца.

**Другая категория, отсекается:** загрузки (Bandcamp, SoundCloud, Audiomack,
ReelCrafter, DISCO, untitled.stream), лицензирование (Songtradr, Tracklib,
Musicbed, Artlist), смартлинки дистрибьюторов (HyperFollow, iMusician,
TuneCore, LANDR Promolinks).

Feature.fm это уже делают. Отличие есть **только для участников записи**.
Базы участий у нас нет: автор вставлял бы ссылки и указывал роль сам.

**Не проверено:** виджет PromoLinks и Feature.fm вживую; функции Muso Pro за
входом; AllMusic (сайт отказал); играет ли TIDAL Credits без входа. Поиск шёл
только из США, Reddit был закрыт, японские источники почти не нашлись.
